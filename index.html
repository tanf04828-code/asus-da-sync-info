ASUS Data Analysis Sync

A personal Windows tool that copies selected analysis files from its owner's computer to a designated folder in the owner's Google Drive.

The tool uses rclone and a Windows scheduled task. It uploads new or changed files, checks their names, sizes and available checksums, and writes a small sync-status file. Local deletion does not request deletion of the corresponding Google Drive copy.

This application is for its owner's personal use. It is not a public storage service and does not accept other users' files.

This website contains application information only. It cannot sign in to Google, access Google Drive, receive file uploads or display the owner's private data.
