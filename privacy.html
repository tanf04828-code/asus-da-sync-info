ASUS Data Analysis Sync

Privacy notice

Effective date: 26 October 2026. This notice describes ASUS Data Analysis Sync, a personal-use tool operated by its owner.

Data accessed and purpose

The tool reads files selected for synchronization on the owner's Windows computer. It uses Google Drive file contents and metadata to copy new or changed files to a designated folder and to verify file names, sizes and available checksums. It also uploads a small synchronization-status file and a dedicated verification file.

Google's requested Drive permission allows broad file access. The local application configuration and command guards restrict this tool's uploads to the designated folder. The tool does not propagate local deletions to Google Drive.

Transfers and sharing

Selected file data is sent directly from the owner's computer to Google Drive. The tool does not send those files to this website or to its GitHub repository. It does not sell file data, use it for advertising or train machine-learning models with it.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Storage and retention

Source files remain on the owner's computer. Uploaded copies remain in the owner's Google Drive until the owner removes them. OAuth credentials and operational logs are stored locally, outside the upload source. Credentials are not included in this public website or repository. Local diagnostic logs rotate, and local run history is bounded.

Owner control

The owner can stop the Windows scheduled task and revoke the application's access through Google account connections. Revoking access stops future authorized API access; it does not remove files already copied to Google Drive.

This website

These static pages contain no analytics scripts, sign-in forms or upload forms. GitHub Pages hosts the website and may process ordinary web-request information under the GitHub privacy statement. Google Drive processes uploaded files under Google's privacy policy.
